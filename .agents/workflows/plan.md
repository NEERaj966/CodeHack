# Plan a milestone

1. Identify the requested outcome, relevant SRS requirement IDs, users/roles, and affected layers.
2. Read current progress and inspect the existing implementation before choosing a design.
3. Set a bounded, observable completion target; separate prerequisite user/host configuration from repository work.
4. List the minimum coherent implementation slices and the focused validations for each.
5. Record any open decision or external blocker; do not inflate the milestone with unrelated P1/P2 work.
